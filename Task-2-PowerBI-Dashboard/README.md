# Task 2: Interactive Power BI Executive Sales & Profit Dashboard

## Objective
Analyze Superstore sales performance, profitability, regional trends, and product performance using an interactive Power BI dashboard.

## Tools Used
- Microsoft Power BI Desktop
- Power Query
- DAX
- Data Modeling

## Dashboard Features
- Executive sales and profit overview
- Key performance indicators (KPIs)
- Regional sales analysis
- Monthly sales trends
- Year-over-year growth analysis
- Product and subcategory profitability
- Interactive filters and slicers

## Key Findings
- Total Sales: 2.30M
- Total Profit: 286.40K
- Profit Margin: 12.47%
