# Task 3: Customer Cohort & Churn Analytics

## Objective
Analyze customer churn, retention patterns, and high-risk customer segments using the IBM Telco Customer Churn dataset.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Analysis
- Customer churn and retention rates
- Contract-wise churn analysis
- Customer tenure cohort analysis
- Payment method analysis
- Monthly charges analysis
- High-risk customer segmentation
- Cohort retention visualization
- Strategic customer retention recommendations

## Key Findings
- Total Customers: 7,043
- Churned Customers: 1,869
- Retained Customers: 5,174
- Churn Rate: 26.54%
- Retention Rate: 73.46%
- Month-to-Month Contract Churn: 42.71%
- Two-Year Contract Churn: 2.83%

## Methodological Limitation
The dataset represents a customer snapshot. Tenure-based retention proportions are used rather than historical cohort retention curves.
