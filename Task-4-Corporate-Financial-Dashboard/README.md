# Task 4: Corporate Financial & Margin Performance Dashboard

## Objective
Analyze corporate financial performance, revenue, discounts, costs, profitability, and budget variance using an interactive Power BI dashboard.

## Tools Used
- Microsoft Power BI Desktop
- Power Query
- DAX
- Data Modeling

## Dashboard Features
- Financial KPI cards
- Corporate income statement
- Revenue to gross profit waterfall analysis
- Quarterly financial performance
- Profit margin by business segment
- Actual vs simulated budget sales analysis
- Interactive year and country slicers

## Key Findings
- Gross Sales: $127.93M
- Total Discounts: $9.21M
- Net Sales: $118.73M
- Cost of Goods Sold: $101.83M
- Gross Profit: $16.89M
- Gross Profit Margin: 14.23%

## Budget Assumption
The simulated sales budget is calculated using previous-year sales with an assumed 10% growth target. It does not represent an actual corporate budget.

## Limitation
Profitability is measured using gross profit margin because operating expense data is unavailable.
