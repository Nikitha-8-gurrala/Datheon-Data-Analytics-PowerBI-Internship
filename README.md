# DATHEON – Data Analytics & Power BI Internship

## Task 1: Exploratory Data Analysis on Superstore Retail Sales

### Objective
Analyze retail sales data to identify sales trends, profitability, customer behavior, and discount patterns.

### Tools Used
- Python
- Pandas
- Matplotlib
- Google Colab

### Analysis Performed
- Data cleaning and missing-value analysis
- Sales and profit KPI calculations
- Category-wise sales and profit analysis
- Region-wise performance analysis
- Monthly sales trends
- Discount versus profit analysis
- Customer segment analysis

### Deliverable
Google Colab Jupyter Notebook with visualizations and five business findings.
